Pertanyaan Umum

Apakah Allium gratis?

Ya, paket dasar gratis selamanya. Paket berbayar tersedia untuk kebutuhan lanjutan.

Bagaimana keamanan data saya?

Kata sandi di-hash dengan algoritma kuat, semua trafik terenkripsi HTTPS, dan sesi dikelola dengan token aman.

Bisakah saya menghapus akun?

Bisa, kapan saja dari dashboard. Seluruh data Anda akan dihapus permanen.

Apakah ada API?

Ada. REST API dengan dokumentasi lengkap tersedia untuk semua pengguna terdaftar.
